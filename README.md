# EatMe для бизнеса — концепт лендинга

Черновой концепт продающей страницы для сервисов доставки рационов питания. Это не официальный сайт.
Цифры, имена, цены и бренды «Овсянка» и FitLab — примеры. Форма заявки ничего никуда не отправляет,
страница не делает сетевых запросов и закрыта от поисковиков (`noindex`).

Страница: https://caypoh23.github.io/eatme-landing-concept/

Шрифты: заголовки — Roboto Flex (SIL Open Font License 1.1, сведения о лицензии внутри файла шрифта),
основной текст — системный шрифт устройства.
